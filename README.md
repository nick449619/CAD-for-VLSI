# CAD-for-VLSI
112-2 CAD for VLSI design

[PA1. Benchmark Translator](https://hackmd.io/@0q1kuGxfTDm_wlE7JXbH3g/H1Ks57P0a) - Implemented a program that reads ISCAS’85 netlist descriptions and converts them into the corresponding gate-level Verilog format.

[PA2. Partitioning](https://hackmd.io/@0q1kuGxfTDm_wlE7JXbH3g/HJ-GwKQWR) - Implemented the Simulated Annealing (SA) algorithm to solve the two-way min-cut partitioning problem.

[PA3. Analog Placement](https://hackmd.io/@0q1kuGxfTDm_wlE7JXbH3g/Sys8zNxVR) - Developed an analog placer using the B*-tree data structure.

[PA4. IR-drop Prediction](https://hackmd.io/@0q1kuGxfTDm_wlE7JXbH3g/ryzkJDLS0) - Trained an IR-drop predictor using XGBoost machine learning.

[PA5. Reinforcement Logic Optimization for a General Cost Function (2024 ICCAD Contest)](https://youtu.be/Md63IQKfBFA) - Implemented a Genetic Algorithm (GA) for logic optimization in circuits.
